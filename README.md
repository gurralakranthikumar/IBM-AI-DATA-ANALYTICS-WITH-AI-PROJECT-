# E-Commerce Sales Analytics with AI

## Project Description
This project analyzes over 150,000 e-commerce transactions from 2021-2025 to extract insights on revenue, product performance, and customer behavior. It includes an unsupervised machine learning model (K-Means Clustering) to segment customers based on purchasing patterns.

## Dataset
**E-Commerce Sales Analytics Dataset** (Kaggle)
Files used: `customer_master.csv`, `dataset_statistics.csv`, `ecommerce_sales_customer_analytics_150k.csv`, `order_items.csv`, `product_catalog.csv`.

## Technologies Used
* Python (Google Colab / Jupyter Notebook)
* Pandas & NumPy for Data Manipulation
* Scikit-Learn for Machine Learning (K-Means)

## Setup and Run Instructions
1. Upload the 5 CSV dataset files into the Python environment.
2. Install required dependencies using `pip install -r requirements.txt`.
3. Execute the Jupyter Notebook (`.ipynb`) cells sequentially to load the data, process the numeric columns, and run the AI segmentation model.
